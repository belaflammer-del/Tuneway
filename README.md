# Tuneway – Demo

Tuner-Vermittlung: Fahrzeug wählen → Setup in der Garage bauen → Tuner in der Nähe vergleichen.

## Auf GitHub Pages veröffentlichen
1. Neues Repository auf github.com anlegen (z. B. `tuneway`), Sichtbarkeit „Public“.
2. Alle Dateien aus diesem Ordner hochladen („Add file“ → „Upload files“).
3. Settings → Pages → Source: „Deploy from a branch“, Branch `main`, Ordner `/ (root)` → Save.
4. Nach 1–2 Minuten ist die Seite unter `https://DEINNAME.github.io/tuneway/` erreichbar.

## Auf den Home-Bildschirm
- iPhone (Safari): Teilen → „Zum Home-Bildschirm“.
- Android (Chrome): Menü ⋮ → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.

## Vor dem Livegang
- Impressum: Postanschrift ergänzen (in `index.html` nach `[Straße und Hausnummer]` suchen).
- AGB rechtlich prüfen lassen, Datenschutzerklärung ergänzen.
- Alle Tuner, Adressen, Bewertungen und Preise sind Beispiele.
